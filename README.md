# Segurança Digital e Prevenção de Golpes Online

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte da Atividade Extensionista II do curso de Gestão da Tecnologia da Informação.

O objetivo é desenvolver recursos digitais educativos para orientar a comunidade sobre a prevenção de golpes online, proteção de dados pessoais e práticas de segurança digital.

## 🎯 Objetivos

- Orientar sobre os principais golpes virtuais.
- Apresentar cuidados relacionados ao PIX, WhatsApp, links suspeitos e redes sociais.
- Incentivar boas práticas de proteção de dados pessoais.
- Avaliar o conhecimento dos participantes por meio de um questionário digital.
- Organizar e apresentar os resultados coletados utilizando Python.

## 🌐 Site educativo

O site educativo foi desenvolvido utilizando o Canva e contém orientações sobre segurança digital e prevenção de golpes online.

**Link do site:** https://xn--seguranadigiital-ipb.my.canva.site/

## 📝 Questionário

Ao final do site educativo, foi disponibilizado um questionário digital para avaliar o conhecimento dos participantes sobre os temas abordados.

## 📊 Análise dos resultados

Os dados coletados foram organizados e apresentados utilizando Python, com contagem das respostas, cálculos de porcentagens e geração de gráficos.

## 💻 Tecnologias utilizadas

- Canva
- Google Forms
- Google Labs
- Python
- GitHub
